# Two Pointers Pattern

## When to use
- Input is sorted or can be sorted
- Finding pairs or triplets
- Comparing elements from both ends
- Sliding window style problems

## Key idea
Use two indices that move based on conditions,
instead of nested loops.

## Common mistakes
- Using extra loops unnecessarily
- Forgetting termination conditions
- Modifying pointers incorrectly

Time Complexity: O(n)  
Space Complexity: O(1)
